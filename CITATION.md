# Citation guidance for the publication library

This repository is an index of publications, not a separately peer-reviewed research publication. Cite the **specific DOI record** for a deposited work, not this repository.

## Deposited research works

For a work deposited in Zenodo, cite its **individual Zenodo record** rather than this registry. Check the authoritative record for its exact title, creator, publication date, version, resource type and DOI before formatting a reference. The README and registry.json are discovery indexes, not replacements for the deposited file or record metadata.

For *The Composer's Prompt* (the exact title in the live Zenodo API; the longer phrase 'Music Theory and Harmony for Computational Music Prompting' appears in its descriptive text), the public Book record was confirmed via the official Zenodo API with HTTP 200 on 6 November 2026 as version **1.0.0**, version DOI **10.5281/zenodo.23689714**. Zenodo identifies **10.5281/zenodo.23689713** as the **concept/all-versions DOI of the same work**, not an unresolved or additional seventh publication. For the specified version, cite the version DOI; use the concept DOI when deliberately referring to all versions. Exact downloaded bytes/checksum have not been independently reverified.

## Archived material

The former research website and notes are preserved in the [archive branch](https://github.com/Joenasriani/joe-research-registry/tree/archive/legacy-research-website-2026-10). These are not additional DOI publications in the six-record index. When citing an archived note, identify the specific archived file and commit or access date.

## Citing this registry

For the changing registry itself, cite the GitHub repository URL together with the specific commit hash or access date. Do not cite the registry as a peer-reviewed academic work.
